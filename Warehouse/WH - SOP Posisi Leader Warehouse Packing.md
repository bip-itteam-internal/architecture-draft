## 001. SOP Memproses Pesananan Toko

**Berkas sumber**: `001. SOP Memproses Pesananan Toko.docx` · **No. dokumen**: 001/WHP/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 27-April-2026 · **Disusun oleh**: SPV Manufacture · **Disetujui oleh**: Direktur

### Tujuan

SOP ini dibuat sebagai pedoman proses penanganan pesanan toko agar seluruh order diproses secara cepat, akurat, rapi, tepat jumlah, tepat produk, dan siap dikirim sesuai target waktu perusahaan.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh proses pemrosesan pesanan toko oleh tim Warehouse Packing, meliputi:
    1. Penerimaan data order toko
    2. Verifikasi pesanan
    3. Prioritas order
    4. Picking barang
    5. Packing barang
    6. Quality check packing
    7. Serah terima ke pengiriman / ekspedisi
    8. Update status order
    9. Penanganan kendala order
- Berlaku khusus untuk area warehouse packing.

### Penanggung Jawab

- Leader Warehouse Packing bertanggungjawab koordinator proses order harian
- Admin Warehouse bertanggungjawab input dan cetak pesanan
- Picker bertanggungjawab mengambil barang sesuai order
- Petugas packing bertanggungjawab packing pesanan
- QC Checker bertanggungjawab final checking
- Supervisor Manufacture bertanggungjawab monitoring KPI operasional

### Definisi

Pesanan Toko adalah permintaan barang dari toko / outlet / customer resmi yang masuk melalui sistem perusahaan.

Picking adalah proses mengambil barang dari rak penyimpanan sesuai order.

Packing adalah proses pengepakan barang agar siap dikirim.

Lead Time Order adalah waktu dari order diterima sampai siap kirim.

Shortage adalah kondisi stok kurang dari jumlah pesanan.

### Rincian Prosedur

1. Penerimaan Pesanan
    - Leader menerima data pesanan dari :
        - Sales admin
        - Marketplace admin
        - Sistem ERP / order management
        - Customer service internal
    - Pesanan harus mencantumkan :
        - Nama customer / customer
        - Nomor order
        - SKU barang
        - Qty
        - Alamat / area kirim
        - Deadline pengiriman
2. Verifikasi Pesanan
    - Leader memastikan :
        - Data lengkap
        - SKU valid
        - Qty sesuai sistem
        - Tidak ada duplikasi order
        - Metode pengiriman jelas
    - Jika data tidak lengkap, dikembalikan ke admin terkait
3. Penentuan Prioritas Order
    - Order diprioritaskan berdasarkan :
        - Same day delivery
        - Pesanan overdue
        - Customer prioritas
        - Order reguler FIFO
        - Order volume besar (sesuai kapasitas)
4. Cetak Picking List
    - Admin/leader mencetak picking list berisi :
        - Nomor order
        - Lokasi rak
        - Nama barang
        - Qty
5. Proses Picking Barang
    - Picker mengambil barang sesuai picking list dengan prinsip :
        - FEFO / FIFO
        - Qty akurat
        - Barang tidak rusak
        - Batch sesuai aturan
6. Serah ke Area Packing
    - Barang hasil picking dipindahkan ke meja packing disertai picking list
7. Proses Packing
    - Packing staff melakukan :
        - Cek ilang SKU dan Qty
        - Gunakan kardus / bubble wrap / seal sesuai standar
        - Pisahkan barang fragile
        - Tempel label pengiriman / resi
8. Final Quality Check
    - Leader / checker memastikan :
        - Barang sesuai order
        - Qty sesuai
        - Packing rapi
        - Tidak ada produk rusak
        - Resi benar
9. Serah Terima Pengiriman
    - Order siap kirim diserahkan ke :
        - Driver internal
        - Kurir
        - Ekspedisi
    - Disertai dokumen jalan / manifest
10. Update Status Sistem
    - Status order diubah menjadi :
        - Packed
        - Ready to ship
        - Shipped
11. Penanganan Kendala
    - Jika terjadi masalah :
    - **Stok Kurang**
        - Informasikan admin sales
        - Buat backorder / partial shipment
    - **Barang Rusak**
        - Pisahkan ke area reject
    - **Salah Picking**
        - Lakukan recount dan koreksi
    - **Order Menumpuk**
        - Tambah manpower / lembur / reprioritas

### SLA/Target Waktu

- Akurasi order - ≥ 99%
- Order selesai sesuai SLA - ≥ 95%
- Salah kirim – 0 major error
- Lead time proses – sesuai cut off
- Productivity packing – sesuai kapasitas harian

### Dokumen Pendukung atau Lampiran

- Sales Order List
- Picking List
- Packing Checklist
- Surat Jalan
- Manifest Pengiriman
- Stock Shortage Report
- Daily Order Report
- Return / Complaint Form

### Distribusi Dokumen

- Warehouse packing
- Supervisor manufacture
- Sales admin
- Finance / Admin

## 002. SOP Quality Control Pesanan

**Berkas sumber**: `002. SOP Quality Control Pesanan.docx` · **No. dokumen**: 002/WHP/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 28-April-2026 · **Disusun oleh**: SPV Manufacture · **Disetujui oleh**: Direktur

### Tujuan

SOP ini dibuat sebagai pedoman pelaksanaan Quality Control (QC) pesanan agar seluruh pesanan yang dikirim ke toko / customer sesuai standar perusahaan, tepat produk, tepat jumlah, kondisi baik, dan meminimalkan kesalahan kirim maupun komplain pelanggan.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh proses pengecekan kualitas pesanan di area Warehouse Packing, meliputi:
    1. Pemeriksaan hasil picking
    2. Pemeriksaan hasil packing
    3. Verifikasi dokumen pengiriman
    4. Pemeriksaan kondisi produk
    5. Pemeriksaan jumlah item
    6. Pemeriksaan label dan alamat
    7. Final release order siap kirim
    8. Penanganan ketidaksesuaian pesanan

### Penanggung Jawab

- Leader Warehouse Packing bertanggungjawab PIC QC pesanan
- Admin Warehouse bertanggungjawab menyiapkan dokumen order
- Picker bertanggungjawab menyiapkan barang sesuai picking list
- Petugas packing bertanggungjawab melakukan packing sesuai standar
- QC Checker / packing checker bertanggungjawab pelaksana pengecekan
- Supervisor Manufacture bertanggungjawab monitoring mutu proses

### Definisi

Quality Control Pesanan adalah proses pemeriksaan untuk memastikan pesanan sesuai data order dan standar pengiriman sebelum dikirim.

Mismatch adalah ketidaksesuaian antara order dengan barang fisik.

Rework adalah proses perbaikan atas kesalahan pesanan.

Release Order adalah status pesanan yang dinyatakan lolos QC dan siap dikirim.

### Rincian Prosedur

1. Penerimaan Order Siap QC
    - Setelah picking dan packing awal selesai, pesanan dipindahkan ke area QC bersama dokumen :
        - Sales order
        - Picking list
        - Packing checklist
        - Label pengiriman
2. Pemeriksaan Dokumen
    - Leader / checker memastikan :
        - Nomor order sesuai
        - Nama toko / customer benar
        - Alamat lengkap
        - SKU dan qty pada dokumen jelas
3. Pemeriksaan Produk Fisik
    - Dilakukan pengecekan :
        - Nama barang sesuai
        - SKU / kode produk sesuai
        - Qty sesuai order
        - Tidak rusak / bocor / penyok
        - Kemasan produk baik
        - Expired date aman
        - Batch sesuai aturan
4. Pemeriksaan Hasil Packing
    - Pastikan :
        - Kardus sesuai ukuran
        - Barang aman saat transit
        - Bubble wrap / filler cukup
        - Tidak overpack / underpack
        - Seal rapat
5. Pemeriksaan Label Pengiriman
    - Cek :
        - Nama penerima
        - Nomor telepon
        - Area kirim
        - Kode ekspedisi
        - Nomor order / barcode
6. Sampling / 100% check
    - Metode QC berdasarkan kategori :
    - **Order Prioritas / High Value**
        - 100% check
    - **Order Reguler**
        - Sampling atau 100% sesuai kebijakan
7. Keputusan QC
    - **Jika Sesuai**
        - Beri status PASS
        - Tempel tanda QC checked
        - Pindah ke area ready to ship
    - **Jika Tidak Sesuai**
        - Status HOLD / FAIL
        - Pisahkan order
        - Lakukan investigasi dan rework
8. Rework Order
    - Kesalahan umum :
        - Salah SKU
        - Kurang qty
        - Lebih qty
        - Packing rusak
        - Label salah
    - Setelah diperbaiki, wajib re-QC
9. Serah Terima Pengiriman
    - Order PASS diserahkan ke tim delivery / ekspedisi
10. Pelaporan Harian
    - Leader membuat laporan :
        - Jumlah order dicek
        - Order pass
        - Order fail
        - Jenis kesalahan
        - Trend error picker / packing

### SLA/Target Waktu

- Akurasi order kirim - ≥ 99%
- Komplain salah kirim - ≤ 1%
- QC completion on time - ≥ 95%
- Rework rate – menurun bulanan
- Damage saat kirim - minimal

### Dokumen Pendukung atau Lampiran

- Sales order
- Picking list
- Packing checklist
- QC checklist order
- Dailty QC report
- Non conformity report
- Rework form
- Shipping manifest

### Distribusi Dokumen

- Warehouse Packing
- Supervisor Manufacture
- Sales Admin
- Direktur

### Flowchart Quality Control Pesanan

*Teks kotak flowchart, menurut urutan tersimpan di dokumen. Panah dan percabangan tidak ikut tersalin.*

1. Terima Order dari Packing
2. Pindah Ready to Ship
3. Serah ke Pengiriman
4. Laporan Harian
5. Cek Packing & Label
6. PASS QC
7. Cek Produk Fisik & Qty
8. Cek Dokumen Order

## 003. SOP Pencocokan Data Pesanan

**Berkas sumber**: `003. SOP Pencocokan Data Pesanan.docx` · **No. dokumen**: 003/WHP/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 28-April-2026 · **Disusun oleh**: SPV Manufacture · **Disetujui oleh**: Direktur

### Tujuan

SOP ini dibuat sebagai pedoman proses pencocokan data pesanan agar seluruh data order yang diterima sesuai dengan dokumen pendukung, stok tersedia, dan siap diproses tanpa kesalahan sehingga meningkatkan akurasi operasional warehouse packing.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh proses verifikasi dan pencocokan data pesanan di Warehouse Packing, meliputi:
    1. Penerimaan data order
    2. Pencocokan sales order dengan sistem
    3. Verifikasi SKU dan quantity
    4. Verifikasi alamat pengiriman
    5. Verifikasi status pembayaran
    6. Pencocokan stok tersedia
    7. Identifikasi order bermasalah
    8. Final release order ke picking process

### Penanggung Jawab

- Leader Warehouse Packing bertanggungjawab PIC proses pencocokan data
- Admin Warehouse bertanggungjawab menarik data order dan input sistem
- Sales admin / CS bertanggungjawab pengirim data pesanan
- Picker tim bertanggungjawab menindaklanjuti order valid
- Supervisor manufacture bertanggungjawab monitoring akurasi proses
- Finance / Admin Penjualan bertanggungjawab validasi pembayaran jika diperlukan

### Definisi

Pencocokan Data Pesanan adalah proses memverifikasi kesesuaian antara data order, dokumen transaksi, dan ketersediaan stok sebelum order diproses.

Sales Order (SO) adalah dokumen resmi permintaan pesanan pelanggan.

Mismatch Data adalah ketidaksesuaian antara data order dengan sistem atau dokumen.

Release Picking adalah status order yang sudah valid dan dapat diproses pengambilan barang.

### Rincian Prosedur

1. Penerimaan Data Pesanan
    - Leader / admin menerima data pesanan dari :
        - Sales admin
        - Marketplace admin
        - Customer service
        - Sistem ERP / Order Management System
    - Data minimal mencakup :
        - Nomor order
        - Nama toko / customer
        - SKU barang
        - Qty
        - Alamat kirim
        - Deadline pengiriman
2. Pemeriksaan Kelengkapan Data
    - Dicek apakah data lengkap dan terbaca jelas.
    - Jika tidak lengkap :
        - Tahan proses order
        - Kembalikan ke pihak pengiriman untuk revisi
3. Pencocokan Dengan Sistem
    - Admin mencocokkan data order dengan sistem :
        - Nomor order valid
        - Customer terdaftar
        - SKU aktif
        - Harga / promo
        - Tidak duplicate order
4. Verifikasi Ketersediaan Stok
    - Cek stok sistem dan stok fisik :
        - Available stock cukup
        - Barang tidak hold
        - Batch tersedia
5. Identifikasi Masalah Order
    - Jenis masalah :
    - **Short Stock**
    - Qty pesanan > stok tersedia
    - **Duplicate Order**
    - Order ganda masuk
    - **Salah SKU**
    - Kode barang tidak sesuai
    - **Data Customer Tidak Lengkap**
    - Alamat / nomor telepon tidak jelas
    - **Hold Payment**
    - Untuk order yang mensyaratkan pembayaran
6. Koordinasi Perbaikan
    - Leader berkoordinasi dengan :
        - Sales admin
        - Finance
        - Customer service
        - Supervisor Manufacture
    - Untuk menyelesaikan mismatch
7. Final Approval Order
    - Jika data valid :
        - Status diubah menjadi ready for picking
        - Cetak picking list
        - Serah ke tim picking
8. Monitoring Prioritas Order
    - Order urgent / same day diberi label prioritas
9. Pelaporan Harian
    - Leader membuat laporan :
        - Total order masuk
        - Order valid
        - Order pending
        - Jenis mismatch
        - Waktu release order

### SLA/Target Waktu

- Akurasi data order - ≥ 99%
- Order release on time - ≥ 95%
- Duplicate order - 0
- Pending karena mismatch – menurun
- Lead time validasi – sesuai SLA

### Dokumen Pendukung atau Lampiran

- Sales order list
- Order management system report
- Stock availability report
- Picking release sheet
- Pending order list
- Daily validation report
- Customer master data
- Escalation form order issue

### Distribusi Dokumen

- Warehouse Packing
- Supervisor Manufacture

## 004. SOP Monitoring Pesanan Tertinggal

**Berkas sumber**: `004. SOP Monitoring Pesanan Tertinggal.docx` · **No. dokumen**: 004/WHP/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 29-April-2026 · **Disusun oleh**: SPV Manufacture · **Disetujui oleh**: Direktur

### Tujuan

SOP ini dibuat sebagai pedoman monitoring pesanan tertinggal agar seluruh order yang belum selesai diproses dapat terdeteksi lebih cepat, ditindaklanjuti tepat waktu, mengurangi keterlambatan pengiriman, serta menjaga kepuasan customer.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh proses pemantauan pesanan tertinggal di area Warehouse Packing, meliputi:
    1. Monitoring order belum dipicking
    2. Monitoring order belum dipacking
    3. Monitoring order pending QC
    4. Monitoring order ready namun belum dikirim
    5. Monitoring overdue order
    6. Investigasi penyebab keterlambatan
    7. Eskalasi dan percepatan penyelesaian
    8. Pelaporan backlog order

### Penanggung Jawab

- Leader Warehouse Packing bertanggungjawab PIC monitoring order tertinggal
- Admin Warehouse bertanggungjawab menarik data order pending
- Picker bertanggungjawab menyelesaikan backlog picking
- Petugas packing bertanggungjawab menyelesaikan backlog packing
- QC Checker / packing checker bertanggungjawab menyelesaikan pending QC
- Supervisor Manufacture bertanggungjawab monitoring KPI backlog

### Definisi

Pesanan Tertinggal adalah pesanan yang belum selesai diproses sesuai SLA / cut off time yang ditetapkan.

Backlog Order adalah akumulasi order pending yang belum selesai.

Overdue Order adalah order yang melewati target waktu proses / kirim.

Escalation adalah pelaporan masalah kepada atasan untuk percepatan keputusan.

### Rincian Prosedur

1. Penarikan Data Order Harian
    - Leader / admin menarik data dari sistem pada interval tertentu :
        - Pagi hari
        - Tengah hari
        - Menjelang cutt off
        - Akhir shift
    - Data mencakup status :
        - New order
        - Picking
        - Packing
        - QC
        - Ready to ship
        - Pending
2. Identifikasi Order Tertinggal
    - Pesanan dikategorikan tertinggal jika :
        - Belum diproses melebihi SLA
        - Tertahan di satu proses terlalu lama
        - Belum kirim sesuai jadwal
        - Order prioritas belum selesai
3. Pengelompokan Penyebab
    - Leader mengidentifikasi penyebab utama :
    - **Operasional**
        - Kekurangan manpower
        - Picking lambat
        - Packing overload
    - **Sistem**
        - Data order error
        - Status tidak update
    - **Persediaan**
        - Stock shortage
        - Barang hold
    - **Pengiriman**
        - Kurir terlambat
        - Armada terbatas
4. Prioritas Penanganan
    - Urutan prioritas :
        - Order overdue
        - Same day delivery
        - Customer prioritas
        - Order volume besar
        - Order reguler lama
5. Tindakan Percepatan
    - Leader melakukan tindakan :
        - Redistribusi manpower
        - Tambah lembur
        - Ubah prioritas picking
        - Buka line packing tambahan
        - Koordinasi ekspedisi
        - Split shipment jika perlu
6. Eskalasi Masalah
    - Jika tidak terselesaikan, leader eskalasi ke supervisor / management untuk :
        - Approval lembur
        - Tambahan tenaga bantu
        - Prioritas stok
        - Keputusan pengiriman alternatif
7. Monitoring Real Time
    - Leader memantau progres tiap 1-2 jam sampai backlog turun
8. Update Sistem
    - Setiap order selesai wajib diupdate status aktual
9. Pelaporan Harian
    - Laporan mencakup :
        - Total order masuk
        - Total order tertinggal
        - Aging backlog
        - Penyebab utama
        - Tindakan korektif
        - Remaining backlog
10. Review Preventif
    - Leader bersama supervisor membuat perbaikan agar backlog tidak terulang

### SLA/Target Waktu

- Order tertinggal harian – minimal
- Overdue order - ≤ 2%
- Backlog recovery rate - ≥ 95%
- Update status akurat - ≥ 99%
- Penyelesaian prioritas order – on time

- Backlog monitoring sheet
- Aging order report
- Manpower allocation sheet
- Escalation form
- Daily productivity report
- Shipping manifest
- Improvement log

### Distribusi Dokumen

## 005. SOP Controlling Tim Warehouse Packing

**Berkas sumber**: `005. SOP Controlling Tim Warehouse Packing.docx` · **No. dokumen**: 005/WHP/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 29-April-2026 · **Disusun oleh**: SPV Manufacture · **Disetujui oleh**: Direktur

### Tujuan

SOP ini dibuat sebagai pedoman controlling tim Warehouse Packing agar aktivitas operasional berjalan disiplin, produktif, akurat, aman, sesuai target harian, serta memastikan seluruh anggota tim bekerja sesuai standar perusahaan.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh proses pengendalian tim Warehouse Packing, meliputi:
    1. Pengaturan manpower harian
    2. Pembagian tugas kerja
    3. Monitoring produktivitas
    4. Monitoring kualitas kerja
    5. Pengawasan disiplin kerja
    6. Pengawasan area kerja dan 5R/5S
    7. Penanganan kendala operasional
    8. Coaching tim
    9. Pelaporan performa tim

### Penanggung Jawab

- Leader Warehouse Packing bertanggungjawab PIC controlling tim harian
- Admin Warehouse bertanggungjawab menjalankan tugas operasional
- Picker bertanggungjawab picking barang
- Petugas packing bertanggungjawab packing barang
- QC Checker bertanggungjawab kontrol kualitas pesanan
- Supervisor Manufacture bertanggungjawab pengawasan keseluruhan
- HRD bertanggungjawab terkait dukungan disiplin manpower

### Definisi

Controlling Tim adalah proses mengatur, mengawasi, mengarahkan, dan mengevaluasi tim agar target kerja tercapai.

Productivity adalah output kerja dibanding waktu / manpower.

Disiplin Kerja adalah kepatuhan terhadap jam kerja, SOP, dan aturan perusahaan.

5R / 5S adalah budaya kerja ringkas, rapi, resik, rawat, rajin.

### Rincian Prosedur

1. Briefing Awal Shift
    - Leader melakukan briefing sebelum kerja dimulai meliputi :
        - Target order
        - Prioritas kerja hari ini
        - Kendala hari sebelumnya
        - Safety reminder
        - Motivasi tim
2. Pengecekan Kehadiran Tim
    - Leader memastikan :
        - Kehadiran lengkap
        - Karyawan terlambat dicatat
        - Kekurangan manpower diantisipasi
    - Jika kurang tenaga kerja :
        - Rotasi area
        - Tambahan helper
        - Eskalasi supervisor
3. Pembagian Tugas Harian
    - Leader membagi personel ke area :
        - Picking
        - Packing
        - QC
        - Loading
        - Admin support
    - Berdasarkan skill dan kebutuhan volume kerja
4. Monitoring Produktivitas
    - Dilakukan berkala tiap jam / sesi :
        - Jumlah order selesai
        - Picking speed
        - Packing speed
        - Pending order
        - Idle manpower
5. Monitoring Kualitas Kerja
    - Leader memastikan :
        - Tidak salah picking
        - Tidak salah packing
        - Packing rapi
        - Area kerja tertib
        - Dokumen lengkap
6. Pengawasan Disiplin
    - Leader mengawasi :
        - Kehadiran
        - Penggunaan HP berlebihan
        - Break time sesuai aturan
        - Kepatuhan seragam / APD
        - Sikap kerja
7. Pengendalian Area Kerja
    - Leader memastikan :
        - Jalur jalan aman
        - Barang tidak menumpuk sembarangan
        - Rak tertata
        - Sampah dibuang
        - Peralatan tersimpan rapi
8. Penanganan Kendala Operasional
    - Contoh kendala :
        - Order overload
        - Printer rusak
        - Stok tidak ketemu
        - Kurang kardus
        - Tim lambat
    - Tindakan :
        - Reprioritas
        - Tambah resource
        - Koordinasi bagian terkait
9. Coaching dan Teguran
    - Untuk performa rendah atau pelanggaran :
        - Coaching langsung
        - Teguran lisan
        - Catatan leader
        - Eskalasi supervisor / HRD bila berulang
10. Closing Shift
    - Leader melakukan :
        - Rekap hasil kerja
        - Pending order
        - Evaluasi manpower
        - Handover shift berikutnya
11. Pelaporan Harian
    - Laporan ke supervisor mencakup :
        - Output tim
        - Backlog
        - Error kerja
        - Kehadiran
        - Kendala utama
        - Improvement suggestion

### SLA/Target Waktu

## 006. SOP Penempatan Produk & Kartu Stok

**Berkas sumber**: `006. SOP Penempatan Produk & Kartu Stok.docx` · **No. dokumen**: 006/WHP/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 29-April-2026 · **Disusun oleh**: SPV Manufacture · **Disetujui oleh**: Direktur

### Tujuan

SOP ini dibuat sebagai pedoman penempatan produk dan pengelolaan kartu stok agar barang tersimpan rapi, mudah ditemukan, aman, serta data persediaan tercatat akurat antara stok fisik dan administrasi.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh aktivitas penempatan produk dan pengendalian kartu di area gudang / warehouse, meliputi :
    1. Penerimaan barang jadi / barang masuk
    2. Penentuan lokasi penyimpanan
    3. Penataan produk di rak / area lantai
    4. Pelabelan lokasi
    5. Pengisian kartu stok
    6. Mutasi barang antar lokasi
    7. Pengeluaran barang untuk picking
    8. Monitoring akurasi stok
    9. Penanganan selisih stok
- Berlaku untuk seluruh area penyimpanan produk

### Penanggung Jawab

- Leader Warehouse Packing bertanggungjawab PIC penempatan produk & kontrol kartu stok
- Admin Warehouse bertanggungjawab update data sistem
- Picker bertanggungjawab pengeluaran barang sesuai prosedur
- QC Checke bertanggungjawab validasi kondisi produk
- Supervisor Manufacture bertanggungjawab monitoring akurasi stok

### Definisi

Penempatan Produk adalah proses menaruh barang pada lokasi penyimpanan yang telah ditentukan agar mudah dikendalikan dan diambil.

Kartu Stok adalah media pencatatan keluar masuk barang per item / lokasi sebagai kontrol persediaan.

Mutasi Barang adalah perpindahan barang antar lokasi penyimpanan.

FIFO / FEFO adalah metode pengeluaran barang berdasarkan tanggal masuk / kadaluarsa.

### Rincian Prosedur

1. Penerimaan Barang
    - Barang diterima dari :
        - Warehouse PT. Bharata Internasional Pharmaceutical
        - Retur layak jual
    - Leader memastikan :
        - Jenis barang sesuai dokumen
        - Qty sesuai
        - Kondisi baik
        - Kemasan aman
2. Penentuan Lokasi Penyimpanan
    - Barang ditempatkan berdasarkan :
        - Kategori produk
        - Fast / slow moving
        - Ukuran barang
        - Batch / expired date
        - Kapasitas rak
        - Kemudahan picking
3. Penataan Produk
    - Staf warehouse menata barang dengan ketentuan :
        - Rapi dan stabil
        - Tidak melebihi kapasitas rak
        - Jalur akses aman
        - Label menghadap depan
        - Batch terpisah jelas
4. Pelabelan Lokasi
    - Setiap lokasi wajib memiliki :
        - Kode rak / bin location
        - Nama area
        - Kapasitas
5. Pengisian Kartu Stok Saat Barang Masuk
    - Setelah penempatan, kartu stok diupdate :
        - Tanggal
        - Nomor dokumen
        - Qty masuk
        - Saldo akhir masuk
        - Nama petugas
6. Pengeluaran Barang
    - Saat barang diambil untuk order :
        - Berdasarkan picking list resmi
        - Gunakan FIFO / FEFO
        - Qty sesuai kebutuhan
7. Update Kartu Stok Saat Barang Keluar
    - Catat :
        - Tanggal
        - Nomor Order
        - Qty keluar
        - Saldo akhir
        - Nama petugas
8. Mutasi Antar Lokasi
    - Jika barang dipindahkan :
        - Catat lokasi asal dan tujuan
        - Update kartu stok kedua lokasi
        - Update sistem bila ada
9. Stock Check Berkala
    - Leader melakukan :
        - Cycle count harian / mingguan
        - Stock opname periodik
        - Audit lokasi acak
10. Penanganan Selisih Stok
    - Jika ada selisih :
        - Hitung ulang fisik
        - Cek kartu stok
        - Cek histori transaksi
        - Investigasi penyebab
        - Laporan ke supervisor
11. Housekeeping Area
    - Pastikan area :
        - Bersih
        - Tidak lembab
        - Aman dari kerusakan
        - Tidak tercampur barang reject

### SLA/Target Waktu

- Akurasi stok - ≥ 99%
- Kartu stok terupdate - 100%
- Waktu pencarian barang - cepat
- Selisih stok – minimal
- Kerapihan area – 100%
