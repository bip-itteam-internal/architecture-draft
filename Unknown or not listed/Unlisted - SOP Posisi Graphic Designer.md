## 052. SOP Brief & Konsep Design

**Berkas sumber**: `052. SOP Brief & Konsep Design.docx` · **No. dokumen**: 052/Skr/SOP/V/2026 · **Revisi**: 00 · **Tanggal**: 20-Mei-2026

### Tujuan

- SOP ini dibuat sebagai pedoman dalam proses penerimaan brief dan pembuatan konsep desain agar:
    - Proses desain berjalan terarah, efektif, dan sesuai kebutuhan perusahaan.
    - Memastikan hasil desain sesuai dengan objective, branding, dan target audiens.
    - Meminimalisir revisi akibat ketidaksesuaian konsep.
    - Meningkatkan kualitas komunikasi antara requester dan Graphic Designer.
    - Menjamin seluruh proses desain terdokumentasi dengan baik.

### Ruang Lingkup

- SOP ini mencakup:
    1. Penerimaan brief desain.
    2. Analisa kebutuhan desain.
    3. Penyusunan konsep desain.
    4. Presentasi konsep desain.
    5. Revisi konsep desain.
    6. Approval konsep desain.
    7. Dokumentasi dan pengarsipan brief desain.

### Penanggung Jawab

1. Graphic Designer bertanggung jawab mengembangkan konsep dan visual design
2. User Departemen bertanggung jawab memberikan brief dan kebutuhan design
3. Direktur bertanggung jawab review dan approval konsep design produk

### Definisi

Penerimaan brief design, analisa brief dan kebutuhan design, pembuatan konsep design, presentasi konsep design, revisi konsep design, approval konsep design, dokumentasi dan pengarsipan.

### Rincian Prosedur

1. Prosedur penerimaan Brief Design :
    - Menerima brief design melalui :
        - Form brief
        - Chat internal
        - Meeting
            - Memastikan brief masuk :
        - Tujuan design
        - Jenis design
        - Ukuran/output design
        - Deadline
        - Referensi visual
            - Mengklarifikasi kebutuhan yang belum lengkap
2. Prosedur Analisa Brief dan Kebutuhan Design :
    - Memahami objektif design
    - Menyesuaikan design sesuai dengan brand guideline
    - Mengidentifikasi kebutuhan visual :
        - Warna
        - Font
        - Style design
        - Layout
            - Mengumpulkan referensi design bila diperlukan
3. Prosedur Pembuatan Konsep Design :
    - Menentukan arah visual design
    - Membuat beberapa alternatif konsep bila diperlukan
    - Menyesuaikan konsep dengan branding guideline perusahaan
    - Menyusun draft konsep design
4. Prosedur Presentasi Konsep Design
    - Menjelaskan konsep visual dan objective design
    - Menyampaikan :
        - Pilihan warna
        - Layout
        - Visual style
        - Pesan komunikasi design
            - Menerima masukan dan feedback
            - Mengembangkan konsep design sesuai hasil diskusi
5. Prosedur Revisi Konsep Design
    - Melakukan revisi design sesuai arahan
    - Menyesuaikan elemen visual yang diperlukan
    - Mengirim hasil revisi kepada requester/supervisor
    - Melakukan revisi lanjutan bila diperlukan
6. Prosedur Approval Konsep Design
    - Memastikan seluruh revisi telah sesuai
    - Mendapatkan approval final design
    - Menyiapkan design untuk proses produksi/publikasi
7. Prosedur Dokumentasi dan Pengarsipan
    - Mengarsipkan :
        - Brief design
        - Draft konsep
        - File revisi
        - Final artwork
    - Menyimpan file dalam format kerja dan final
    - Backup file design secara digital.

5. Prosedur Revisi dan Finalisasi Design
    - Melakukan revisi sesuai arahan

## 056. SOP Standarisasi Brand Visual

**Berkas sumber**: `056. SOP Standarisasi Brand Visual.docx` · **No. dokumen**: 056/Skr/SOP/V/2026 · **Revisi**: 00 · **Tanggal**: 20-Mei-2026

### Tujuan

- SOP ini dibuat sebagai pedoman dalam penerapan standarisasi brand visual perusahaan agar :
    - Seluruh materi visual perusahaan memiliki identitas yang konsisten
    - Meningkatkan profesionalitas dan citra perusahaan
    - Memastikan penggunaan elemen visual sesuai branding guideline
    - Mempermudah proses produksi design antar departemen
    - Menghindari penyalahgunaan identitas visual perusahaan

### Ruang Lingkup

- SOP ini mencakup:
    1. Penggunaan logo perusahaan
    2. Standarisasi warna dan tipografi
    3. Penggunaan elemen visual perusahaan
    4. Penerapan brand visual pada media digital dan cetak
    5. Review kesesuaian design dengan branding
    6. Dokumentasi dan pengarsipan aset visual perusahaan

### Penanggung Jawab

1. Graphic Designer bertanggung jawab menerapkan dan menjaga konsistensi brand visual
2. Supervisor bertanggung jawab review dan approval implementasi visual

### Definisi

Penyusunan brand visual guideline, penggunaan logo dan identitas visual, standarisasi warna dan typography, penerapan brand visual pada media, review dan kontrol kualitas visual, distribusi aset brand visual, dokumentasi dan pengarsipan.

### Rincian Prosedur

1. Prosedur penyusunan brand visual guideline :
    - Menentukan elemen visual perusahaan :
        - Logo
        - Warna utama dan pendukung
        - Typography
        - Iconografi
        - Layout style
    - Membuat panduan penggunaan visual
    - Menentukan aturan :
        - Ukuran logo
        - Area aman logo
        - Warna yang diperbolehkan
        - Penggunaan background
            - Mendokumentasikan guideline visual
2. Prosedur Penggunaan Logo dan Identitas Visual :
    - Menggunakan file logo resmi perusahaan
    - Memastikan warna logo sesuai standar
    - Tidak mengubah :
        - Bentuk logo
        - Proporsi logo
    - Menempatkan logo sesuai layout guideline
3. Prosedur Standarisasi Warna dan Typography :
    - Menggunakan font yang telah ditentukan
    - Menyesuaikan hierarchy typography :
        - Headline
        - Subheadline
        - Body text
            - Menghindari penggunaan font atau warna di luar standar tanpa approval
4. Prosedur Penerapan Brand Visual pada Media
    - Menerapkan branding pada :
        - Social media
        - Poster
        - Banner
        - Packaging
        - Website
        - Presentasi
        - Merchandise
    - Menyesuaikan format design dengan media yang digunakan
    - Memastikan visual tetap konsisten di semua platform
5. Prosedur Review dan Kontrol Kualitas Visual
    - Review design sebelum dipublikasikan atau dicetak
    - Memastikan :
        - Logo sesuai standar
        - Warna dan font sesuai guideline
        - Layout konsisten
    - Memberikan revisi bila ditemukan ketidaksesuaian
    - Mendokumentasikan hasil review visual
6. Prosedur Distribusi Aset Brand Visual
    - Menyiapkan :
        - Logo master
        - Template design
        - Font resmi
        - Colour palette
    - Mengirim aset kepada :
        - Internal department
        - Vendor
        - Partner terkait
    - Memastikan aset yang digunakan merupakan versi terbaru
7. Prosedur Dokumentasi dan Pengarsipan
    - Mengarsipkan :
        - Brand guideline
        - Logo master
        - Template desain
        - Aset visual
        - Data revisi guideline
    - Menyimpan file secara digital dan backup server
    - Menjaga keamanan aset visual perusahaan.
