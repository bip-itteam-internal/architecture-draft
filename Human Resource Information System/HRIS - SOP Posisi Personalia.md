## 014. SOP Administrasi Data Karyawan

**Berkas sumber**: `014. SOP Administrasi Data Karyawan.docx` · **No. dokumen**: 014/HRD/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 24-Apr-2026 · **Disusun oleh**: Supervisor HRGA · **Disetujui oleh**: Direktur

### Tujuan

Sebagai pedoman pengelolaan administrasi data karyawan agar seluruh data personalia tersimpan rapi, akurat, aman, mudah diakses sesuai kewenangan, dan mendukung kebutuhan operasional serta kepatuhan perusahaan.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh proses administrasi data karyawan PT. Bharata Internasional Pharmaceutical, meliputi:
    1. Data karyawan baru
    2. Perubahan data karyawan aktif
    3. Arsip dokumen personal file
    4. Data payroll pendukung
    5. Data kontrak kerja
    6. Data mutasi / promosi / demosi
    7. Data resign / termination
    8. Data BPJS / NPWP / rekening
    9. Data digital di HRIS / spreadsheet / sistem

### Penanggung Jawab

1. HR Personalia bertanggung jawab sebagai pengelola utama data karyawan
2. HR Supervisor bertanggungjawab review dan kontrol data
3. Finance bertanggungjawab penggunaan data payroll terkait
4. User Departemen bertanggung jawab menginformasikan perubahan data tim
5. IT Support bertanggungjawab menjaga keamanan sistem data
6. Karyawan bertanggung jawab memberikan data yang valid dan terbaru

### Definisi

Administrasi Data Karyawan adalah proses pencatatan, penyimpanan, pembaruan, pengarsipan, dan pengendalian seluruh data karyawan perusahaan.

Personal File adalah berkas fisik atau digital yang berisi dokumen resmi karyawan.

HRIS adalah sistem informasi SDM untuk penyimpanan dan pengelolaan data karyawan.

### Rincian Prosedur

1. Penerimaan Data Karyawan Baru
    - Saat onboarding, HRD menerima dokumen :
        - KTP
        - KK
        - NPWP
        - BPJS Kesehatan
        - Rekening Bank
        - Ijazah
        - CV
        - Foto
        - Surat Pengalaman Kerja(opsional)
2. Verifikasi Dokumen
    - HRD memeriksa :
        - Kelengkapan dokumen
        - Kejelasan data
        - Kesesuaian nama/identitas
        - Masa berlaku dokumen tertentu
    - Jika belum lengkap, HRD meminta perlengkapan ke karyawan yang bersangkutan
3. Input Data ke Sistem
    - HRD menginput data ke database / HRIS :
        - Nama lengkap
        - NIK internal
        - Jabatan
        - Departemen
        - Tanggal masuk
        - Status kerja
        - Salary code
        - Kontak darurat
4. Pembuatan Personal File
    - HRD membuat file karyawan fisik / digital berisi seluruh dokumen resmi
5. Pembaruan Data Karyawan Aktif
    - Perubahan data wajib dilaporkan oleh karyawan, contoh :
        - Alamat
        - Nomor Hp
        - Status pernikahan
        - Rekening bank
        - Pendidikan terbaru
        - Kontak darurat
    - HRD memperbarui data maksimal sesuai SLA/Target Waktu
6. Perubahan Status Karyawan
    - Jika terjadi perubahan :
        - Perpanjangan kontrak
        - Pengangkatan kontrak
        - Mutasi
        - Promosi
        - Demosi
        - Perubahan salary grade
    - HRD mengupdate data sistem dan dokumen pendukung
7. Pengelolaan Dokumen Resign
    - Jika karyawan resign :
        - Ubah status nonaktif
        - Arsip dokumen
        - Mengisi form exit clearance
        - Simpan histori kerja
        - Proses paklaring
8. Pengamanan Data
    - HRD wajib menjaga :
        - Kerahasiaan data pribadi
        - Akses terbatas
        - Backup data berkala
        - Penyimpanan aman
9. Audit dan Rekonsiliasi Data
    - Secara berkala dilakukan pengecekan :
        - Data aktif vs payroll
        - Data kontrak jatuh tempo
        - Kelengkapan dokumen
        - Duplikasi data

### SLA/Target Waktu

- Input data karyawan baru – maksimal H+1 join
- Update perubahan data – maksimal 3 hari kerja
- Arsip dokumen resign – maksima 7 hari kerja
- Audit data berkala – bulanan / triwulan

### Dokumen Pendukung atau Lampiran

- Form Data Karyawan Baru
- Checklist Dokumen Karyawan
- Database Master Karyawan
- Form Perubahan Data Karyawan
- Surat Keputusan Mutasi / Promosi
- Kontrak Kerja
- Exit Clearance Form
- Personal File Karyawan

### Distribusi Dokumen

1. HR Personalia
2. HR Supervisor
3. Finance
4. IT Support
5. Direktur

### Flowchart Administrasi Data Karyawan

*Teks kotak flowchart, menurut urutan tersimpan di dokumen. Panah dan percabangan tidak ikut tersalin.*

1. Terima Data / Dokumen Karyawan
2. Verifikasi Kelengkapan
3. Input ke HRIS / Database
4. Buat Personal File
5. Update Berkala jika Terjadi Perubahan
6. Monitoring Status Karyawan
7. Audit Data Berkala
8. Arsip Jika Resign

## 015. SOP Absensi dan Cuti

**Berkas sumber**: `015. SOP Absensi dan Cuti.docx` · **No. dokumen**: 015/HRD/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 24-Apr-2026 · **Disusun oleh**: Supervisor HRGA · **Disetujui oleh**: Direktur

### Tujuan

Sebagai pedoman pengelolaan absensi dan cuti agar kehadiran karyawan tercatat akurat, disiplin kerja terjaga, proses pengajuan cuti berjalan tertib, serta mendukung kelancaran operasional perusahaan.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh karyawan PT. Bharata Internasional Pharmaceutical, meliputi:
    1. Karyawan tetap
    2. Karyawan kontrak
    3. Karyawan masa evaluasi
    4. Intership / magang (sesuai kebijakan)
- Ruang lingkup pengaturan mencakup :
    1. Kehadiran harian
    2. Keterlambatan
    3. Pulang cepat
    4. Izin tidak masuk
    5. Sakit
    6. Cuti tahunan
    7. Cuti khusus sesuai ketentuan
    8. Rekap absensi untuk payroll

### Penanggung Jawab

1. Karyawan bertanggungjawab melakukan absensi dan pengajuan cuti
2. User Departemen bertanggungjawab approval izin / administrasi cuti
3. HR Personalia bertanggungjawab monitoring absensi dan administrasi cuti
4. HR Supervisor bertanggungjawab pengawasan kepatuhan karyawan
5. Finance bertanggungjawab menggunakan data absensi untuk payroll
6. IT Support bertanggungjawab menjaga sistem absensi

### Definisi

Absensi adalah pencatatan kehadiran karyawan saat masuk dan pulang kerja melalui sistem yang ditetapkan perusahaan.

Cuti adalah hak tidak masuk kerja yang diberikan sesuai ketentuan perusahaan dan peraturan yang berlaku.

Izin adalah ketidakhadiran sementara karena alasan tertentu di luar cuti tahunan.

Terlambat adalah kehadiran melewati jam kerja yang ditentukan.

### Rincian Prosedur

1. Prosedur Abensi Harian
    - Karyawan wajib melakukan absensi :
        - Saat masuk kerja
        - Saat pulang kerja
        - Saat dinas luar
        - Shift tertentu sesuai jadwal
    - Media absensi dapat berupa :
        - Fingerprint
        - Mobile attendance
2. Jam Kerja
    - Jam kerja mengikuti kebijakan perusahaan, keterlambatan dihitung jika melebihi toleransi yang diterapkan
3. Lupa Absensi
    - Jika lupa absen :
        - Karyawan mengajukan koreksi absensi
        - Disertai alasan
        - Approval atasan
        - HRD melakukan penyesuaian bila valid
4. Ketidakhadiran Karena Sakit
    - Karyawan wajib :
        - Menginformasikan atasan dan HRD secepatnya
        - Menyampaikan surat dokter bila diperlukan
5. Pengajuan Izin
    - Untuk keperluan mendesak, karyawan mengajukan izin melalui sistem / form dengan persetujuan atasan
6. Pengajuan Cuti Tahunan
    - Langkah pengajuan :
        - Karyawan cek saldo cuti
        - Ajukan cuti minimal H-7
        - Atasan review kebutuhan operasional
        - Approval / reject
        - HRD update saldo cuti
7. Cuti Khusus
    - Jenis cuti khusus mengikuti peraturan perusahaan :
        - Menikah (5 hari)
        - Istri melahirkan (3 hari)
        - Kedukaan keluarga inti (2 hari)
        - Keperluan tertentu sesuai kebijakan
8. Penolakan / Penjadwalan Ulang Cuti
    - Atasan dapat menolak / menunda cuti jika :
        - Operasional kritis
        - Pengganti tidak tersedia
        - Periode sibuk perusahaan
    - Dengan tetap mengedepankan komunikasi dan hak karyawan
9. Monitoring dan Rekap Bulanan
    - HRD melakukan rekap :
        - Kehadiran
        - Terlambat
        - Alpha
        - Izin
        - Sakit
        - Cuti terpakai / sisa
10. Monitoring dan Rekap Bulanan
    - Pelanggaran absensi berulang dapat dikenakan pembinaan / sanksi sesuai aturan perusahaan

### SLA/Target Waktu

- Pengajuan cuti reguler – minimal H-5
- Approval atasan – maksimal 2 hari kerja
- Update saldo cuti – maksimal hari H approval
- Rekap absensi bulanan – maksimal tanggal payroll

### Dokumen Pendukung atau Lampiran

- Form Pengajuan Cuti
- Form Izin Tidak Masuk
- Form Perbaikan Absensi
- Rekap Absensi Bulanan
- Saldo Cuti Karyawan
- Surat Dokter
- Peraturan Jam Kerja
- Surat Teguran Disiplin

### Distribusi Dokumen

1. HR Personalia
2. HR Supervisor
3. Finance
4. IT Support
5. Direktur

### Flowchart Absensi dan Cuti

*Teks kotak flowchart, menurut urutan tersimpan di dokumen. Panah dan percabangan tidak ikut tersalin.*

1. Karyawan Masuk Kerja
2. Melakukan Absensi
3. Izin / Sakit / Cuti Ajukan Permohonan
4. Approval Atasan
5. HR Update Sistem

7. Data ke Payroll

## 016. SOP Kontrak Kerja

**Berkas sumber**: `016. SOP Kontrak Kerja.docx` · **No. dokumen**: 016/HRD/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 24-Apr-2026 · **Disusun oleh**: Supervisor HRGA · **Disetujui oleh**: Direktur

### Tujuan

Sebagai pedoman pengelolaan kontrak kerja agar proses pembuatan, perpanjangan, perubahan, dan pengakhiran hubungan kerja berjalan tertib, sesuai peraturan yang berlaku, serta melindungi kepentingan perusahaan dan karyawan.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh proses administrasi kontrak kerja di PT. Bharata Internasional Pharmaceutical, meliputi:
    1. PKWT (Perjanjian Kerja Waktu Tertentu)
    2. PKWTT (Perjanjian Kerja Waktu Tidak Tertentu)
    3. Masa Evaluasi
    4. Addendum Kontrak
    5. Perpanjangan Kontrak
    6. Perubahan Jabatan / Penempatan
    7. Berakhirnya Kontrak Kerja
    8. Pengarsipan Dokumen Kerja

### Penanggung Jawab

1. HR Personalia bertanggungjawab administrasi kontrak kerja
2. HR Supervisor bertanggungjawab review isi kontrak
3. User Departemen bertanggungjawab memberi rekomendasi status karyawan
4. Legal bertanggungjawab review kepatuhan hukum
5. Direktur bertanggungjawab approval final kontrak posisi tertentu
6. Karyawan bertanggungjawab membaca dan menandatangani kontrak

### Definisi

Kontrak Kerja adalah perjanjian tertulis antara perusahaan dan karyawan yang memuat hak, kewajiban, masa kerja, jabatan, kompensasi, dan ketentuan lainnya.

PKWT adalah hubungan kerja untuk jangka waktu tertentu sesuai ketentuan hukum yang berlaku.

PKWTT adalah hubungan kerja tetap / tidak dibatasi waktu.

Addendum adalah perubahan atau penambahan isi kontrak yang disepakati kedua pihak.

### Rincian Prosedur

1. Persiapan Kontrak Karyawan Baru
    - Setelah kandidat menerima penawaran kerja, HRD menyiapkan draft kontrak berisi :
        - Nama karyawan
        - Jabatan
        - Departemen
        - Lokasi kerja
        - Tanggal mulai kerja
        - Masa berlaku kontrak
        - Gaji dan benefit
        - Jam kerja
        - Hak dan kewajiban
        - Ketentuan disiplin
        - Klausul kerahasiaan
2. Review Internal
    - Draft kontrak direview oleh :
        - HR Supervisor
        - Direktur
        - Legal
3. Penandatanganan Kontrak
    - Kontrak ditandatangani oleh :
        - Pihak perusahaan berwenang
        - Karyawan
    - Dilakukan sebelum mulai kerja atau sesuai ketentuan yang berlaku
4. Distribusi Dokumen
    - Setelah ditandatangani :
        - 1 copy untuk perusahaan
        - 1 copy untuk karyawan
        - Softcopy diarsipkan HRD
5. Monitoring Masa Berlaku
    - HRD melakukan monitoring jatuh tempo kontrak melalui reminder system :
        - H-60
        - H-30
        - H-14
6. Evaluasi Menjelang Berakhir
    - Atasan langsung memberikan rekomendasi :
        - Diperpanjang
        - Diangkat tetap
        - Tidak diperpanjang
    - Berdasarkan kinerja, disiplin, kebutuhan organisasi
7. Perpanjang Kontrak
    - Jika dilanjutkan :
        - HRD menyiapkan kontrak baru / addendum
        - Approval internal
        - Tanda tangan sebelum kontrak lama berakhir
8. Perubahan Isi Kontrak
    - Jika ada perubahan :
        - Jabatan
        - Lokasi kerja
        - Salary structure
        - Penugasan khusus
    - Maka dibuat addendum resmi
9. Pengakhiran Kontrak
    - Jika berakhir / tidak diperpanjang :
        - HRD menginformasikan secara resmi
        - Proses clearance
        - Pengembalian aset
        - Final settlement sesuai ketentuan
        - Arsip status nonaktif
10. Penyimpanan Dokumen
    - Seluruh kontrak disimpan aman dalam personal file dan arsip digital

### SLA/Target Waktu

- Draft kontrak baru – maksimal H-3 sebelum join
- Reminder kontrak berakhir – H-60 / H-30 / H-14
- Keputusan perpanjangan - maksimal H-14
- Addendum perubahan – maksimal 7 hari kerja
- Arsip final dokumen – maksimal H+3

### Dokumen Pendukung atau Lampiran

- Draft PKWT / PKWTT
- Offering Letter
- Approval Hiring
- Form Evaluasi Karyawan
- Form Rekomendasi Perpanjangan
- Addendum Kontrak
- Exit Clearance Form
- Dashboard Personal Karyawan

### Distribusi Dokumen

1. HR Personalia
2. Karyawan
3. Finance
4. User Departemen
5. Direktur

### Flowchart Kontrak Kerja

*Teks kotak flowchart, menurut urutan tersimpan di dokumen. Panah dan percabangan tidak ikut tersalin.*

## 017. SOP Payroll

**Berkas sumber**: `017. SOP Payroll.docx` · **No. dokumen**: 017/HRD/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 24-Apr-2026 · **Disusun oleh**: Supervisor HRGA · **Disetujui oleh**: Direktur

### Tujuan

Sebagai pedoman proses payroll agar penggajian karyawan berjalan tepat waktu, akurat, rahasia, sesuai kebijakan perusahaan, serta memenuhi kewajiban perpajakan dan ketenagakerjaan yang berlaku.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh proses penggajian PT. Bharata Internasional Pharmaceutical, meliputi:
    1. Gaji pokok
    2. Tunjangan tetap / tidak tetap
    3. Lembur
    4. Insentif / bonus
    5. Potongan absensi
    6. BPJS
    7. PPh 21
    8. Pinjaman / potongan khusus
    9. THR
    10. Slip gaji
    11. Transfer payroll
- Berlaku untuk :
    1. Karyawan tetap
    2. Karyawan kontrak
    3. Masa evaluasi
    4. Magang/Internship

### Penanggung Jawab

1. HR Personalia bertanggungjawab menyiapkan data payroll
2. HR Supervisor bertanggungjawab review data SDM
3. Finance bertanggungjawab proses perhitungan gaji
4. User Departemen Finance bertanggungjawab approval pembayaran
5. IT Support bertanggungjawab dukungan sistem payroll
6. Direktur bertanggungjawab approval final payroll

### Definisi

Payroll adalah proses perhitungan, persetujuan, dan pembayaran kompensasi karyawan sesuai periode penggajian perusahaan.

Gross Salary adalah total pendapatan sebelum potongan.

Net Salary / Take Home Pay adalah gaji bersih setelah potongan.

Cut Off Payroll adalah batas akhir data yang masuk untuk perhitungan gaji periode berjalan.

### Rincian Prosedur

1. Penetapan Periode Payroll
    - Payroll dilakukan sesuai jadwal perusahaan, misalnya bulanan
    - HRD menetapkan :
        - Periode kerja
        - Tanggal cut off
        - Tanggal pembayaran gaji
2. Pengumpulan Data Payroll
    - HRD mengumpulkan data pendukung :
        - Rekap absensi
        - Keterlambatan
        - Alpha / izin / cuti
        - Lembur
        - Perubahan gaji
        - Karyawan join / resign
        - Pinjaman karyawan
        - Potongan disiplin
3. Validasi Data
    - HRD memeriksa :
        - Data kehadiran
        - Status karyawan
        - Kontrak aktif
        - Salary Update
        - Kelengkapan approval lembur
4. Input ke Sistem Payroll
    - Payroll officer menginput seluruh data ke software / file payroll
5. Proses Perhitungan Gaji
    - Komponen Perhitungan :
    - **Pendapatan**
        - Gaji pokok
        - Tunjangan
        - Lembur
    - **Potongan**
        - BPJS
        - PPh 21
        - Potongan absensi
        - Pinjaman / kasbon
        - Potongan lain yang sah
6. Review dan Rekonsiliasi
    - Dilakukan pengecekan :
        - Perubahan ekstrim nominal
        - Double payment
        - Kesalahan rekening
        - Karyawan non aktif masih terbayar
7. Approval Payroll
    - Draft payroll diajukan kepada :
        - HR Supervisor
        - FAT Supervisor
        - Direktur
8. Pembayaran Gaji
    - Setelah approval :
        - Transfer bank massal
        - Cash khusus jika diizinkan
    - Dilakukan sesuai tanggal gajian
9. Distribusi Slip Gaji
    - Slip gaji dibagikan melalui :
        - Email resmi
        - Sistem HRIS
        - Amplop tertutup
10. Penanganan Pertanyaan Payroll
    - Karyawan dapat mengajukan klarifikasi dalam batas waktu yang ditentukan
11. Arsip Payroll
    - Semua data payroll diarsipkan secara aman dan rahasia

### SLA/Target Waktu

- Cut off data absensi – tanggal 26 setiap bulan
- Draft payroll selesai – tanggal 28 sebelum gajian
- Pembayaran gaji – setiap tanggal 1 awal bulan
- Slip gaji terdistribusi – H+2 hari kerja

### Dokumen Pendukung atau Lampiran

- Rekap absensi bulanan
- Data lembur
- Surat perubahan gaji
- Data join / resign
- Master salary list
- File payroll
- Slip gaji
- Bukti transfer payroll

## 018. SOP BPJS & Benefit

**Berkas sumber**: `018. SOP BPJS & Benefit.docx` · **No. dokumen**: 018/HRD/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 24-Apr-2026 · **Disusun oleh**: Supervisor HRGA · **Disetujui oleh**: Direktur

### Tujuan

Sebagai pedoman pengelolaan BPJS dan benefit karyawan agar proses pendaftaran, perubahan data, pembayaran iuran, serta pemberian fasilitas kesejahteraan berjalan tertib, tepat waktu, sesuai ketentuan, dan mendukung kesejahteraan karyawan.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh pengelolaan BPJS dan benefit di PT. Bharata Internasional Pharmaceutical, meliputi:
    1. BPJS Kesehatan
    2. BPJS Ketenagakerjaan

## 019. SOP Disiplin Kerja

**Berkas sumber**: `019. SOP Disiplin Kerja.docx` · **No. dokumen**: 019/HRD/SOP/IV/2026 · **Revisi**: 00 · **Tanggal**: 24-Apr-2026 · **Disusun oleh**: Supervisor HRGA · **Disetujui oleh**: Direktur

### Tujuan

Sebagai pedoman penerapan disiplin kerja agar tercipta lingkungan kerja yang tertib, profesional, produktif, aman, serta mendukung budaya kerja perusahaan dan pencapaian target organisasi.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh karyawan PT. Bharata Internasional Pharmaceutical, meliputi:
    1. Karyawan tetap
    2. Karyawan kontrak
    3. Karyawan dalam masa evaluasi
    4. Internship / magang
    5. Supervisor dan seluruh level jabatan
- Ruang lingkup disiplin kerja mencakup :
    1. Kehadiran dan ketepatan waktu
    2. Kepatuhan terhadap jam kerja
    3. Kepatuhan SOP kerja
    4. Etika dan perilaku kerja
    5. Penggunaan fasilitas perusahaan
    6. Kepatuhan K3 / keamanan kerja
    7. Kepatuhan instruksi atasan yang sah
    8. Tata tertib / peraturan perusahaan

### Penanggung Jawab

1. Seluruh karyawan bertanggung jawab mematuhi aturan disiplin kerja
2. User Departemen bertanggung jawab monitoring dan pembinaan tim
3. HRD bertanggungjawab administrasi pelanggaran dan pembinaan
4. HR Supervisor bertanggungjawab review kasus disiplin
5. Direktur bertanggungjawab mengambil keputusan pada kasus berat
6. Security bertanggungjawab dukungan ketertiban area kerja

### Definisi

Disiplin Kerja adalah kepatuhan karyawan terhadap seluruh peraturan, tata tertib, kebijakan, dan standar perilaku perusahaan.

Pelanggaran Disiplin adalah tindakan atau kelalaian yang bertentangan dengan ketentuan perusahaan.

Pembinaan adalah tindakan korektif awal untuk memperbaiki perilaku kerja.

Sanksi adalah konsekuensi administratif atas pelanggaran yang terbukti.

### Rincian Prosedur

1. Standar Disiplin Kerja
    - Setiap karyawan wajib :
        - Hadir tepat waktu
        - Melakukan absensi sesuai aturan
        - Mematuhi jam kerja dan jam istirahat
        - Menjalankan tugas sesuai SOP
        - Menjaga etika dan sopan santun
        - Menjaga aset perusahaan
        - Menjaga kerahasiaan data perusahaan
        - Menggunakan APD / mengikuti K3 bila diwajibkan
2. Jenis Pelanggaran
    - **Pelanggaran ringan**
        - Terlambat berulang
        - Lupa absensi
        - Tidak menjaga kebersihan area kerja
        - Lalai administrasi ringan
    - **Pelanggaran sedang**
        - Mangkir tanpa izin
        - Menolak instruksi kerja yang sah
        - Mengganggu ketertiban kerja
        - Kelalaian yang menyebabkan kerugian ringan
        - Perilaku tidak sopan
    - **Pelanggaran berat**
        - Pemalsuan data
        - Titip absen / manipulasi absensi
        - Pencurian
        - Kekerasan / ancaman
        - Penyalahgunaan wewenang
        - Membocorkan rahasia perusahaan
        - Tindakan melanggar hukum
    - Segala pelanggaran yang belum tercatat didalam SOP, bisa langsung dicek dalam peraturan perusahaan.
3. Temuan Pelanggaran
    - Pelanggaran dapat diketahui melalui :
        - Atasan langsung
        - HRD
        - CCTV / sistem
        - Laporan saksi
        - Audit internal
4. Klarifikasi
    - HRD / atasan memanggil karyawan untuk memberikan penjelasan dan klarifikasi
5. Investigasi
    - Jika diperlukan dilakukan pemeriksaan data :
        - Rekam absensi
        - CCTV
        - Email / dokumen kerja
        - Saksi terkait
6. Penentuan Tindakan
    - Berdasarkan hasil klasifikasi :
    - **Ringan**
        - Teguran lisan
        - Coaching
    - **Sedang**
        - Surat peringatan(SP)
        - Pembinaan tertulis
        - Monitoring khusus
    - **Berat**
        - SP tingkat lanjut
        - Skorsing sesuai yang ada dalam peraturan perusahaan
        - Pemutusan hubungan kerja sesuai ketentuan
7. Dokumentasi
    - Seluruh tindakan disiplin dicatat dalam file karyawan
8. Monitoring Perbaikan
    - Atasan dan HRD memonitor perubahan perilaku setelah pembinaan
9. Eskalasi
    - Jika pelanggaran berulang, sanksi dapat ditingkatkan sesuai ketentuan perusahaan

### SLA/Target Waktu

- Klarifikasi awal – maksimal 3 hari kerja
- Investigasi kasus – maksimal 7 hari kerja
- Penerbitan surat tindakan – maksimal 3 hari setelah keputusan
- Monitoring perbaikan – 1 sampai 3 bulan

## 044. SOP Perjalanan Dinas & Akomodasi

**Berkas sumber**: `044. SOP Perjalanan Dinas & Akomodasi.docx` · **No. dokumen**: 044/GA/SOP/V/2026 · **Revisi**: 00 · **Tanggal**: 17-Mei-2026

### Tujuan

- SOP ini dibuat sebagai pedoman dalam pengelolaan perjalanan dinas dan akomodasi karyawan agar:
    - Proses perjalanan dinas berjalan tertib, efektif, dan terorganisir.
    - Kebutuhan transportasi dan akomodasi terpenuhi sesuai standar perusahaan.
    - Penggunaan biaya perjalanan dinas lebih terkontrol dan efisien.
    - Mempermudah koordinasi administrasi perjalanan dinas.
    - Mendukung kelancaran aktivitas operasional perusahaan di luar kantor.

### Ruang Lingkup

- SOP ini mencakup :
    1. Pengajuan perjalanan dinas
    2. Persetujuan perjalanan dinas
    3. Pemesanan transportasi dan akomodasi
    4. Pengelolaan biaya perjalanan dinas
    5. Dokumentasi perjalanan dinas
    6. Pelaporan dan pengarsipan administrasi perjalanan dinas

### Penanggung Jawab

1. Admin General Affair bertanggung jawab mengelola administrasi perjalanan dinas dan akomodasi
2. Karyawan bertanggung jawab mengajukan dan melaksanakan perjalanan dinas
3. Supervisor HRGA bertanggung jawab approval perjalanan dinas
4. FAT bertanggung jawab verifikasi biaya dan reimbursement perjalanan

### Definisi

Pengajuan perjalanan dinas, approval perjalanan dinas, persiapan transportasi dan akomodasi, pengelolaan biaya perjalanan, pelaksanaan perjalanan dinas, pelaporan dan reimbursement, pengarsipan dokumen.

### Rincian Prosedur

1. Pengajuan Perjalanan Dinas
    - Mengisi form perjalanan dinas
    - Mencantumkan :
        - Nama peserta perjalanan
        - Tujuan perjalanan
        - Kota tujuan
        - Jadwal perjalanan
        - Estimasi biaya
    - Melampirkan surat tugas atau kebutuhan kegiatan
    - Mengajukan approval kepada atasan terkait
2. Approval Perjalanan Dinas
    - Memeriksa kebutuhan perjalanan dinas
    - Verifikasi jadwal dan estimasi biaya
    - Memastikan perjalanan sesuai kebutuhan operasional perusahaan
    - Memberikan persetujuan atau revisi pengajuan
3. Persiapan Transportasi dan Akomodasi
    - Memesan :
        - Tiket transportasi
        - Hotel/penginapan
        - Kendaraan operasional
    - Menyesuaikan pemesanan dengan budget perusahaan
    - Menyusun itinerary perjalanan
    - Mengirim detail perjalanan kepada peserta dinas.
4. Pengelola Biaya Perjalanan
    - Mengajukan cash advance bila diperlukan
    - Dokumentasi biaya perjalanan :
        - Tiket
        - Hotel
        - Transportasi lokal
        - Konsumsi
    - Koordinasi dengan FAT tekait pembayaran
    - Monitoring penggunaan biaya perjalanan
5. Pelaksanaan Perjalanan Dinas
    - Melaksanakan kegiatan sesuai surat tugas
    - Menjaga nama baik perusahaan selama perjalanan dinas
    - Menyimpan seluruh bukti transaksi perjalanan
    - Melaporkan kendala perjalanan bila ada
6. Pelaporan dan Reimbursement
    - Menyusun laporan perjalanan dinas
    - Mengumpulkan bukti transaksi
    - Mengajukan reimbursement biaya sesuai ketentuan
    - Verifikasi laporan oleh atasan dan FAT
7. Pengarsipan Dokumen
    - Mengarsipkan :
        - Form Perjalanan Dinas
        - Surat Tugas
        - Tiket dan invoice
        - Bukti pembayaran
        - Laporan perjalanan
    - Menyimpan data secara fisik dan digital
    - Menjaga keamanan dokumen administrasi perjalanan
8. Skala Uang Saku Berdasarkan jarak dan level jabatan
    - Dinas Lokal
        - 0-20 km (masih dalam area oprasional perusahaan ) = Tidak di berikan uang saku dan akomodasi penginaman
    - Dinas Dekat
        - 21-50 km ( Estimasi durasi perjalanan 2-5 jam, Pulang pergi)
            - Uang saku :
            - Level Staff: Rp. 50.000
            - Level SPV : Rp. 75.000 Level Manager: Rp. 100.000
    - Dinas jauh
        - 51-300 km (Perjalanan Lintas Kota besar)
            - Level Staff: Rp. 100.000
            - Level SPV : Rp. 150.000 Level Manager: Rp. 200.000
            - 5.9 Skala Uang Penginapan
    - Dinas jauh
        - 51-300 km (Perjalanan Lintas Kota besar)
            - Level Staff: Rp. 250.000
            - Level SPV : Rp. 350.000
