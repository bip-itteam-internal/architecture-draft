## 026. SOP Penyusunan Rencana Kerja dan Anggaran Tahunan HRGA

**Berkas sumber**: `026. SOP Penyusunan Rencana Kerja dan Anggaran Tahunan HRGA.docx` · **No. dokumen**: 026/HRD/SOP/V/2026 · **Revisi**: 00 · **Tanggal**: 17-Mei-2026

### Tujuan

- SOP ini dibuat untuk memastikan proses penyusunan rencana kerja dan anggaran tahunan Departemen HRGA berjalan secara:
    - Terstruktur dan sistematis.
    - Selaras dengan target dan strategi perusahaan.
    - Efektif dalam pengelolaan sumber daya manusia dan general affair.
    - Tepat waktu dalam proses pengajuan dan persetujuan anggaran.
    - Menjadi acuan pelaksanaan program kerja HRGA selama 1 tahun berjalan.

### Ruang Lingkup

- SOP ini mencakup :
    1. Penyusunan program kerja tahunan HRGA.
    2. Penyusunan anggaran biaya HRGA.
    3. Pengumpulan kebutuhan dari setiap fungsi HRGA.
    4. Evaluasi kebutuhan operasional dan pengembangan SDM.
    5. Proses review, revisi, dan approval.
    6. Distribusi dokumen final rencana kerja dan budget tahunan.

### Penanggung Jawab

1. Supervisor HRGA bertanggung jawab menyusun draft rencana kerja dan anggaran tahunan HRGA
2. Staf HRGA bertanggung jawab memberikan data kebutuhan dan usulan program
3. Tim FAT bertanggung jawab verifikasi kesesuaian anggaran
4. Direktur bertanggung jawab memberikan persetujuan final

### Definisi

Persiapan penyusunan, pengumpulan usulan program dan kebutuhan, penyusunan draft rencana kerja dan anggaran, review dan evaluasi, persetujuan direktur, distribusi dan implementasi.

### Rincian Prosedur

1. Persiapan Penyusunan
    - Mengumpulkan target perusahaan tahun berjalan
    - Mengkaji evaluasi program HRGA tahun sebelumnya
    - Mengumpulkan data realisasi budget tahun sebelumnya
    - Menentukan timeline penyusunan
2. Pengumpulan Usulan Program dan Kebutuhan
    - Mengirim form usulan program kerja kepada staf terkait
    - Mengumpulkan kebutuhan :
        - Recruitment
        - Training
        - Employee engagement
        - Pengembangan budaya perusahaan
        - General affair
        - Perawatan fasilitas
        - Pengadaan inventaris
    - Mengumpulkan estimasi biaya masing-masing program.
3. Penyusunan Draft Rencana Kerja dan Anggaran
    - Menyusun prioritas program kerja
    - Menentukan target KPI setiap program
    - Menyesuaikan program dengan visi, misi dan target perusahaan
    - Menghitung total estimasi biaya
    - Membuat draft rencana kerja dan anggaran tahunan
4. Review dan Evaluasi
    - Presentasi draft rencana kerja dan anggaran tahunan
    - Evaluasi efektivitas program
    - Evaluasi kemampuan anggaran perusahaan
    - Revisi jika diperlukan
5. Persetujuan Direktur
    - Pengajuan dokumen final
    - Review direktur
    - Approval atau revisi tambahan
6. Distribusi dan Implementasi
    - Distribusi softcopy dan hardcopy
    - Penyimpanan dokumen pada server perusahaan
    - Sosialisasi target dan program kerja kepada tim HRGA

## 027. SOP Mengontrol Pencapaian KPI Staf HRGA

**Berkas sumber**: `027. SOP Mengontrol Pencapaian KPI Staf HRGA.docx` · **No. dokumen**: 027/HRD/SOP/V/2026 · **Revisi**: 00 · **Tanggal**: 17-Mei-2026

### Tujuan

SOP ini dibuat sebagai pedoman dalam proses monitoring, controlling, dan evaluasi pencapaian Key Performance Indicator (KPI) staff HRGA agar seluruh target kerja tercapai secara efektif, terukur, konsisten, dan selaras dengan target perusahaan.

### Ruang Lingkup

- SOP ini berlaku untuk seluruh aktivitas pengendalian KPI staff HRGA, meliputi:
    - Penyusunan KPI staff HRGA
    - Monitoring pencapaian KPI
    - Evaluasi performa berkala
    - Analisa gap pencapaian
    - Coaching dan corrective action
    - Pelaporan KPI
    - Tindak lanjut improvement performa
- Berlaku untuk seluruh staff di Departemen HRGA.

### Penanggung Jawab

1. Supervisor HRGA bertanggung jawab PIC controlling KPI HRGA
2. Staf HRGA bertanggung jawab menjalankan dan melaporkan KPI
3. Direktur bertanggung jawab monitoring KPI departemen

### Definisi

KPI (Key Performance Indicator) adalah indikator terukur yang digunakan untuk menilai pencapaian target kerja karyawan.

Monitoring KPI adalah proses pemantauan progress pencapaian target kerja secara berkala.

Corrective Action adalah tindakan perbaikan terhadap KPI yang belum tercapai.

Performance Review adalah evaluasi performa karyawan berdasarkan hasil KPI.

### Rincian Prosedur

1. Penyusunan KPI Staf HRGA
    - Supervisor HRGA menyusun KPI berdasarkan :
        - Target perusahaan
        - Jobdesk masing-masing staf
        - Prioritas departemen
        - Historical perfomance
        - Project tahunan
    - KPI harus :
        - Spesifik
        - Measurable
        - Achievable
        - Relevant
2. Sosialisasi KPI
    - Supervisor menjelaskan kepada staf :
        - Target KPI
        - Cara pengukuran
        - Bobot penilaian
        - Deadline pencapaian
        - Konsekuensi evaluasi
3. Monitoring Berkala
    - Monitoring dilakukan :
        - Mingguan
        - Bulanan
        - Quartely
    - Yang dimonitor :
        - Progres target
        - Kendala kerja
        - Realisasi KPI
        - Kualitas hasil kerja
4. Pengumpulan Data KPI
    - Staf HRGA wajib menyerahkan :
        - Data realisasi kerja
        - Bukti pendukung
        - Report KPI
        - Progres improvement
5. Verifikasi Data
    - Supervisor melakukan pengecekan :
        - Validitas data
        - Kesesuaian bukti
        - Keakuratan perhitungan
        - Konsistensi pencapaian
6. Analisa Gap KPI
    - Jika target tidak tercapai, supervisor menganalisa :
        - Penyebab utama
        - Kendala operasional
        - Kompetensi staf
        - Beban kerja
        - Faktor eksternal/internal
7. Coaching dan Corrective Action
    - Supervisor memberikan :
        - Coaching
        - Feedback
        - Pendampingan kerja
        - Action plan improvement
        - Penyesuaian target
8. Evaluasi Performa Berkala
    - Dilakukan evaluasi terkait :
        - KPI achievement
        - Attitude kerja
        - Disiplin
        - Inisiatif
        - Improvement mindset
9. Pelaporan KPI
    - Supervisor membuat laporan kepada management terkait :
        - Achievement KPI
        - Staf perfomance
        - Area improvement
        - Risiko departemen
        - Rekomendasi pengembangan
10. Tindak Lanjut
    - Hasil KPI digunakan untuk :
        - Perfomance appraisal
        - Reward dan recognition
        - Training need
        - Promosi / mutasi
        - Corrective action

### SLA/Target Waktu

- Penyusunan KPI – awal periode kerja
- Monitoring KPI – mingguan / bulanan
- Evaluasi KPI – bulanan / quarterly
- Coaching perbaikan – maksimal 7 hari setelah evaluasi
- Pelaporan KPI – maksimal tanggal 5 bulan berikutnya

- KPI Monitoring Sheet
- Perfomance Review Form
- Coaching Form
- Corrective Action Plan
- Achievement Report
- Bukti KPI
- Summary Perfomance Report
