## 052. SOP Input & Verifikasi Data Produksi

**Berkas sumber**: `052. SOP Input & Verifikasi Data Produksi.docx` · **No. dokumen**: 052/WH/SOP/V/2026 · **Revisi**: 00 · **Tanggal**: 18-Mei-2026 · **Disusun oleh**: SPV Manufacture · **Disetujui oleh**: Direktur

### Tujuan

- SOP ini dibuat sebagai pedoman dalam proses input dan verifikasi data produksi agar:
    - Data produksi tercatat secara akurat, lengkap, dan tepat waktu.
    - Meminimalisir kesalahan pencatatan dan input data produksi.
    - Mendukung monitoring hasil produksi dan penggunaan bahan baku.
    - Mempermudah proses pelaporan dan analisis produksi.
    - Menjamin keterlacakan data produksi untuk kebutuhan audit dan evaluasi.

### Ruang Lingkup

- SOP ini mencakup :
    1. Penerimaan data produksi harian
    2. Input data hasil produksi
    3. Verifikasi data produksi
    4. Pencatatan penggunaan bahan baku
    5. Pelaporan data produksi
    6. Pengarsipan dokumen produksi

### Penanggung Jawab

- Admin Produksi bertanggung jawab melakukan input dan verifikasi data produksi
- Operator Produksi bertanggung jawab memberikan data hasil produksi
- Leader Produksi bertanggung jawab mengawasi dan memvalidasi data produksi
- PPIC bertanggung jawab monitoring data produksi dan perencanaan produksi
- Quality Control bertanggung jawab verifikasi hasil kualitas produksi
- Warehouse bertanggung jawab koordinasi data penggunaan bahan baku

### Definisi

Penerimaan data produksi, input data produksi, verifikasi data produksi, verifikasi penggunaan bahan baku, pembuatan laporan produksi, tindak lanjut ketidaksesuaian data, pengarsipan dokumen.

### Rincian Prosedur

1. Penerimaan Data Produksi
    - Menerima dokumen produksi :
        - Form hasil produksi
        - Batch record
        - Form penggunaan bahan baku
        - Data reject produksi
    - Memastikan dokumen lengkap dan telah ditandatangani pihak terkait
    - Mengelompokkan data berdasarkan batch atau tanggal produksi
2. Input Data Produksi
    - Input data :
        - Tanggal produksi
        - Nama produk
        - Nomor batch
        - Quantity hasil produksi
        - Quantity reject
        - Penggunaan bahan baku
    - Memastikan data sesuai dengan dokumen produksi
    - Menyimpan data input produksi
3. Verifikasi Data Produksi
    - Membandingkan data input dengan dokumen produksi
    - Verifikasi :
        - Quantity hasil produksi
        - Batch number
        - Penggunaan bahan baku
        - Data reject
    - Koordinasi dengan operator atau leader produksi bila terdapat ketidaksesuaian
    - Melakukan revisi data bila diperlukan
4. Verifikasi Penggunaan Bahan Baku
    - Memeriksa data pemakaian bahan baku
    - Membandingkan dengan standar formulasi
    - Koordinasi dengan tim warehouse dan produksi bila ada selisih
    - Mendokumentasikan hasil verifikasi
5. Pembuatan Laporan Produksi
    - Menyusun laporan :
        - Hasil produksi
        - Reject produksi
        - Pemakaian bahan baku
        - Efisiensi produksi
    - Mengirim laporan kepada supervisor manufacture dan departemen terkait
    - Backup data laporan produksi
6. Tindak Lanjut Ketidaksesuaian Data
    - Mengidentifikasi penyebab ketidaksesuaian
    - Koordinasi dengan operator/leader produksi
    - Melakukan koreksi data sesuai approval
    - Mendokumentasikan revisi data produksi
7. Pengarsipan Dokumen
    - Mengarsipkan :
        - Form hasil produksi
        - Batch record
        - Form penggunaan bahan baku
        - Laporan produksi
        - Data reject
    - Menyimpan dokumen secara fisik dan digital
    - Menjaga keamanan dan kerahasiaan data produksi.

## 053. SOP Pelaporan Produksi

**Berkas sumber**: `053. SOP Pelaporan Produksi.docx` · **No. dokumen**: 053/WH/SOP/V/2026 · **Revisi**: 00 · **Tanggal**: 18-Mei-2026 · **Disusun oleh**: SPV Manufacture · **Disetujui oleh**: Direktur

### Tujuan

- SOP ini dibuat sebagai pedoman dalam proses pelaporan produksi agar:
    - Data hasil produksi terdokumentasi secara akurat, lengkap, dan tepat waktu.
    - Mempermudah monitoring pencapaian target produksi perusahaan.
    - Mendukung analisis efisiensi dan evaluasi proses produksi.
    - Memastikan keterlacakan data produksi untuk kebutuhan audit dan quality control.
    - Menjadi dasar pengambilan keputusan operasional dan perencanaan produksi.

### Ruang Lingkup

- SOP ini mencakup:
    1. Pengumpulan data produksi.
    2. Penyusunan laporan produksi harian dan periodik.
    3. Verifikasi data hasil produksi.
    4. Pelaporan penggunaan bahan baku dan reject produksi.
    5. Distribusi laporan produksi.
    6. Pengarsipan dokumen produksi.

### Penanggung Jawab

- Admin Produksi bertanggung jawab menyusun dan mendokumentasikan laporan produksi
- Operator Produksi bertanggung jawab memberikan data hasil produksi
- Supervisor Manufacture bertanggung jawab verifikasi dan approval laporan produksi
- PPIC bertanggung jawab monitoring pencapaian produksi
- Quality Control bertanggung jawab verifikasi hasil kualitas produksi
- Warehouse bertanggung jawab koordinasi data bahan baku

### Definisi

Pengumpulan data produksi, verifikasi data produksi, penyusunan laporan produksi, review dan approval laporan, distribusi laporan produksi, tindak lanjut permasalahan produksi, pengarsipan dokumen.

### Rincian Prosedur

1. Pengumpulan Data Produksi
    - Menerima dokumen :
        - Form hasil produksi
        - Batch record
        - Data reject
        - Data downtime
        - Form penggunaan bahan baku
    - Memastikan dokumen lengkap dan telah ditandatangani
    - Mengelompokkan data berdasarkan tanggal atau batch produksi
2. Verifikasi Data Produksi
    - Memeriksa :
        - Quantity hasil produksi
        - Nomor batch
        - Penggunaan bahan baku
        - Data reject
        - Downtime produksi
    - Membandingkan dengan target produksi
    - Koordinasi dengan leader/supervisor manufacture bila ada ketidaksesuaian data
    - Melakukan revisi data bila diperlukan.
3. Penyusunan Laporan Produksi
    - Membuat laporan :
        - Hasil produksi
        - Target vs actual produksi
        - Reject produksi
        - Penggunaan bahan baku
        - Downtime mesin/produksi
        - Efisiensi produksi
    - Menginput data ke sistem atau template laporan perusahaan
    - Memastikan format laporan sesuai standar perusahaan
4. Review dan Approval Laporan
    - Memeriksa keakuratan laporan
    - Verifikasi pencapaian target produksi
    - Memberikan revisi bila diperlukan
    - Menyetujui laporan produksi final
5. Distribusi Laporan Produksi
    - Mengirim laporan kepada :
        - PPIC
        - Quality Control
        - Warehouse
    - Memastikan laporan diterima sesuai jadwal
    - Menyimpan backup laporan produksi
6. Tindak Lanjut Permasalahan Produksi
    - Mengidentifikasi :
        - Selisih hasil produksi
        - Tingginya reject
        - Downtime tinggi
    - Koordinasi dengan tim produksi terkait
    - Mendokumentasikan tindakan perbaikan
    - Monitoring tindak lanjut perbaikan produksi
7. Pengarsipan Dokumen
    - Mengarsipkan :
        - Laporan produksi
        - Batch record
        - Data reject
        - Data downtime
        - Form penggunaan bahan baku
    - Menyimpan dokumen fisik dan digital
    - Menjaga keamanan dan kerahasiaan data produksi
